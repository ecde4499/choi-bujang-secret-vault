로그인 뒤에도 서버가 승인된 기기 상태와 현재 기기 서명을 확인하기 전에는 보호 자료를 표시하지 않습니다.

설치형 웹앱

설치 상태를 확인하는 중입니다.

설치 표시는 편의를 위한 기능이며 기기 승인이나 자료 접근 권한의 근거가 아닙니다. 오프라인에서는 보호 자료를 저장하거나 보여 주지 않습니다.

로그인

로그인됨

로그인 토큰은 HttpOnly 세션 쿠키로 서버 함수에 전달되며 화면 코드에서 읽지 않습니다.

기기 승인

기기 상태 확인 전

로그인 뒤 서버에서 등록·승인 상태를 확인합니다.

승인 요청 버튼은 등록 요청만 만듭니다. 실제 자료 접근은 서버의 승인 기록과 WebAuthn 기기 서명을 모두 확인한 뒤에만 허용됩니다.

승인된 기기에서도 기존 소유자 검사를 그대로 유지합니다. 목록·조회·수정·삭제는 본인 메모만 허용됩니다.
